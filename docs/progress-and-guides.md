# 種目別の成長・ガイドの追加（2026-10-07）

## 使い方

- トレーニング：これまで通り重量・回数を保存。各種目から「実績・推移を見る」「初めてなら、どの重さから？」を開けます。
- 記録 → 種目別の成長：最高重量とその回数、直近の最高重量、前回との差、実施回数・累計セットを表示。グラフと一覧は30日・90日・全期間で切り替えます。
- 記録 → 実施履歴：セットの編集・削除。体重・体脂肪率の記録も同じ「記録」内で利用できます。
- ガイド：フォーム・始め方／食事のヒントを切り替えます。食事は場面別の献立例と、主食・主菜・副菜の有無による助言です。
- 左下のキャラクター：成長・名前・オーラ・実績コレクション・デイリークエスト・ログイン報酬を開きます。独立したマイキャラのナビボタンはありません。閉じると元の画面に戻ります。

## 集計の定義

`lib/strength.ts` は、完了したトレーニングの保存済みセットから表示値を計算します。既存記録もそのまま対象になります。保存方式やDBスキーマの変更はありません。

- 最高重量：その回の当該種目の最大重量。同じ重量のセットが複数あれば最多回数のセットを採用。
- 全期間の最高：重量を優先し、同じ重量なら回数を比較。同条件なら最新の記録を表示。
- 前回との差：直近2回の「その回の最高重量」の差。回数が違う可能性があり、筋力そのものの増減とは断定しません。
- 総負荷量：各セットの重量 × 回数の合計（kg・回）。実際の力学的な仕事量や消費エネルギーではありません。
- 記録中・空のトレーニングは除外。同日に複数回実施した場合は別々に表示。編集・削除後も元記録から再計算。
- 上部の実績は全期間、グラフと一覧は選択期間。最高重量は1RMの推定ではありません。マシン・設定・可動域が異なる場合の比較はできません。

## 確認方法

```sh
node node_modules/typescript/bin/tsc --noEmit
node --test tests/strength.mjs
npm run build
node tests/integration.mjs
```

集計の並び順、同日複数回、未完了除外、重量と回数の対応、総負荷量、0kg、小数、編集・削除による再集計、食事の未確認／不足の区別を確認します。既存の結合テストで記録の保存・認証・ユーザー間分離・体重管理などを検証します。
